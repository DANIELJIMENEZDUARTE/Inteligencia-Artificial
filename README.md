## Cómo ejecutar los programas en Java

Cada proyecto se compila y ejecuta por separado, desde su propia carpeta:

```bash
cd U1/ArbolBinario    # o U1/8_Puzzle
javac -d bin src/principal/*.java
java -cp bin principal.App
```
